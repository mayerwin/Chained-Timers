v1.3.7 — headset routing for voice cues

• New "When a headset is connected" setting (Headset only / Both / Speaker only). Default: Headset only.
• Voice cues now respect your choice via Android's setPreferredDevice — the speaker stays silent when you're wearing headphones.
• Chime / 3-2-1 tick / chain-end finale still ring through both outputs so an alarm-style cue can't go unheard.
• Live-applies to a running chain; takes effect at the next segment.
