v1.4.7 — Numpad picker & polish

• Pixel Clock–style numpad picker: digits shift left as you type — 11515 → 1h 15m 15s.
• Preset chips now ADD to the current value (+10s, +30s, +1m, +2m, +5m, +10m).
• Android back button navigates in-app instead of exiting.
• Segments with no name stay silent (no more "Segment" TTS).
• Chain name is editable while running.
• Card totals now read as "1h 5m 30s".
