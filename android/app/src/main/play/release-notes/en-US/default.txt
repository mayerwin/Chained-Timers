v1.3.6 — voice cues work when minimized + zero-latency segment names

• Every segment's name is now pre-rendered to a WAV file on chain start, cached in app storage. The foreground service plays the right file at each boundary — runs whether the WebView is open, locked, or backgrounded.
• Zero TTS lag: the audio is on disk before the segment begins, so the voice fires the exact instant the boundary lands.
• Files are reused across runs of the same chain.
